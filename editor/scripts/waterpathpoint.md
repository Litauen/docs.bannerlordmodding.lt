# WaterPathPoint

!!! info "v1.4.8"

An empty marker. It has no panel fields and no vanilla scene places it.

Find placed ones with `s:WaterPathPoint`. See [Filter](/editor/editor/#filter).

## Where you put it

Add the script to an entity if you want the marker in the script list. Nothing reads these entities.

## What you set

The script adds no fields.

## What it does

The entity stays where you put it. The class has no tick, no init, and no other caller.

## Where it lives

Managed script. No `scene.xscene` and no prefab under Native, SandBox, SandBoxCore, StoryMode, or NavalDLC stores it.

## Examples

No placed entity. There is no other caller.
