# PopupSceneBanner

!!! info "v1.4.8"

Empty script. No panel fields. No vanilla scene or prefab stores it, and nothing in the managed scripts reads it.

Find placed ones in the Scene panel with `s:PopupSceneBanner`. See [Filter](/editor/editor/#filter).

## Where you put it

Adding it to an entity does not change the scene. Notification banners are placed by spawn points and banner data, not by this script.

## What you set

No fields.

## What it does

The script has no behavior.

## Where it lives

Managed script. Not stored under Native, SandBox, SandBoxCore, StoryMode, or NavalDLC scenes or prefabs.

## Examples

No placement.
