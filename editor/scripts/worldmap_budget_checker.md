# worldmap_budget_checker

!!! info "v1.4.8"

A native script in the editor list, beside the other world-map tools. No official scene or prefab stores it, and no panel field is saved under this name.

Find placed ones in the Scene panel with `s:worldmap_budget_checker`. See [Filter](/editor/editor/#filter).

## Where you put it

Add the script to an entity if you want it in the script list. Nothing in Native, SandBox, SandBoxCore, StoryMode, or NavalDLC places it.

## What you set

Native panel. No `<variable>` row exists for this script, and no property string is paired with the class. The opened modules do not show a field to set.

## What it does

There is no placed entity to read. The class is only in the editor binary.

## Where it lives

Native script. No `scene.xscene` and no prefab under Native, SandBox, SandBoxCore, StoryMode, or NavalDLC stores it.

No placed entity.
